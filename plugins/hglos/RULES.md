# HGLOS 상시 규칙 (정본)

스킬은 불렸을 때만 읽힌다. 아래 규칙은 **스킬이 안 불린 세션에서도** 지켜야 하므로 프로젝트 지침 파일
(`AGENTS.md` / `CLAUDE.md`)에 둔다. 이 파일이 정본이고, 프로젝트 지침 파일에는 맨 아래 "붙여넣기 블록"만 둔다.
규칙을 바꿀 때는 이 파일을 고치고 붙여넣기 블록을 다시 복사한다.

## 1. 대장 파일은 한 작성자만 쓴다
미결 목록, 우려 목록, 진도표처럼 여러 세션이 갱신하는 파일은 **현재 작성자 한 명**만 쓴다.
다른 세션·도구는 결과 보고에 "등록 제안"만 적는다.
작성자는: 쓰기 직전 다시 읽고 크기·행 수 확인 → 최소 변경 → 쓴 직후 `git diff -- <파일>` 로 의도한 행만 바뀌었는지 확인.
읽은 뒤 외부 변경이 보이면 덮어쓰지 말고 멈춘다.
> 근거: 둘이 같은 대장을 쓰다 나중 쪽이 앞 편집을 조용히 덮은 사고(실측 1건).

## 2. 문서 개정은 덧붙이기가 아니라 교체다
같은 주제를 다루는 기존 서술을 문서 전체에서 찾아 낡은 것은 지우거나 새 절을 가리키는 한 줄로 바꾼다.
정정 이력이 필요하면 결정 로그에 남기고, 본문은 현재 상태만 말하게 한다.
기계 점검: `python <hglos 스킬 디렉토리>/scripts/stale_ids.py --ledger <대장> <문서 폴더>` (세 스킬 번들 모두에 들어 있다) - 닫힌 ID 가 "대기·남은" 맥락에 남은 줄을 찾는다.
> 근거: 새 절 옆에 낡은 판이 남아 위에서 읽는 사람이 낡은 쪽을 나중에 만난 사례 3건(실측).

## 3. 판정 어휘
판정 칸에는 **통과 / 미달 / 조건부(조건 열거) / 측정 불가 / 미검증**만 쓴다.
"대체로 통과", "문제없어 보임", "추후 확인"은 판정이 아니다. 증거 없는 통과가 실패이고, 모르는 것은 "미검증"이다.

## 4. 세는 것은 스크립트로
개수·집합·형식 주장은 실행한 스크립트의 출력만 근거로 쓴다. 개수가 아니라 이름을 양방향으로 대조한다
(`set_diff.py`). 계획 문서에는 좌표·개수·전수 주장을 쓰지 않고 `[미확인]` 으로 둔다.
> 근거: 세지 않고 쓴 숫자가 한 slice 에서 4번 틀렸다(13→18, 17→18, 12→13, 4→6).

**검사 스크립트는 실패 경로부터 실측한다.** 판정에 쓰기 전에 일부러 틀린 입력(해시 1개 변조 사본 등)으로 0 이 아닌 종료 코드가
나오는지 먼저 본다. exit 0 은 검사가 돌았다는 증거가 아니다. 실행 셸을 가정하지 않는다(Windows pwsh 에는 `bash`·`sha256sum` 이 없다).
> 근거: 무결성 검사가 실행 셸 부재로 돌지 않았는데 로그는 exit=0 이었던 사례(실측).

## 5. 검증은 새 세션에서, 검증자를 기록한다
검증 세션은 만든 세션과 맥락을 공유하지 않는다(새 서브에이전트 또는 새 세션). 검증자 순위:
다른 회사 모델 → 같은 회사의 비슷한 수준 다른 모델 → 같은 모델. 만든 쪽이 스스로 판정하는 것은 금지.
모든 검증 보고 머리에 `검증자: <모델/버전> · 순위 · 세션 · 구현자와 같은 패밀리: 예/아니오` 를 적고, 보고 원문은 파일로 남긴다.

## 6. 미심쩍은 것은 우려 대장에
확인하지 못했거나 근거가 약한 것은 대화에 흘리지 말고 우려 대장(예: `doc/CONCERNS.md`)에 등록 제안한다.
항목마다 검증 방법과 닫히는 조건을 적는다. 조건 없는 미결은 만들지 않는다.

## 붙여넣기 블록 (프로젝트 AGENTS.md / CLAUDE.md 용)

```markdown
## HGLOS 상시 규칙 (정본: HGLOS 플러그인 RULES.md)
- 대장 파일(<경로들>)은 <작성자>만 쓴다. 다른 세션은 보고서에 등록 제안만.
- 문서 개정은 교체. 낡은 서술을 남기지 않는다. 점검: stale_ids.py
- 판정 어휘: 통과 / 미달 / 조건부 / 측정 불가 / 미검증. "대체로", "추후 확인" 금지
- 개수·집합 주장은 스크립트 출력만 근거. 이름을 양방향 대조(set_diff.py)
- 검사 스크립트는 판정 전에 일부러 틀린 입력으로 실패 종료를 먼저 확인. 셸 가정 금지(pwsh 에 bash 없음)
- 검증은 맥락 분리(새 서브에이전트/세션). 순위: 다른 회사 → 같은 회사 다른 모델 → 같은 모델. 보고 머리에 검증자·순위 기록, 원문은 파일로
- 미확인·우려는 <우려 대장 경로>에 등록 제안. 닫히는 조건 필수
```
